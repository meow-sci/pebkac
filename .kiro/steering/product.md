# Product Overview

PEBKAC (Problem Exists Between Kitten and Chair) is a web-based tool for converting CSV data of celestial bodies into Kitten Space Agency (KSA) XML format.

## Core Functionality
- Import CSV data representing solar system bodies (planets, moons, asteroids, etc.)
- Parse and validate celestial body orbital parameters
- Generate KSA-compatible `<System />` XML for game mod integration
- Interactive grid-based selection of celestial bodies
- Real-time XML preview and editing

## Target Users
- KSA game modders creating custom solar systems
- Space enthusiasts working with orbital mechanics data
- Users wanting to import real astronomical data into KSA

## Key Features
- Default dataset of 476+ Sol system bodies
- Monaco editor integration for CSV/XML editing
- AG Grid for data visualization and selection
- PowerShell scripts for generating updated orbital data
- File System Access API integration for seamless file handling

The tool bridges the gap between astronomical data sources and game-ready XML format for the Kitten Space Agency game.
